# Ethics

# 1. Cognitive Sovereignty

認知主権は、

- Mental Privacy
- Mental Integrity
- Cognitive Liberty
- Psychological Continuity
- 精神的オフライン権
- Control of Cognitive Infrastructure

を束ねる上位原則として扱う。

中心となる問いは、

> **自分が何者になるかを誰が決めるのか**

である。

---

# 2. Cognitive Intervention Levels

すべての認知への影響を同一視しない。

| Level | 介入 | 例 |
|---|---|---|
| L1 | Direct Neural Actuation | 神経刺激 |
| L2 | Neural Inference | 神経信号からの推論 |
| L3 | Adaptive Cognitive Manipulation | 個人状態に適応した推薦や誘導 |
| L4 | Ordinary Information / Persuasion | 通常の情報、広告、助言 |

L1 / L2はCognitive Sovereignty Architectureが直接制御すべき領域である。

L3は技術・制度双方の課題になる。

L4は通常の情報倫理や表現の問題と区別する。

---

# 3. Psychological Continuity

Psychological Continuityは既存の神経倫理で扱われる概念であり、人格や精神生活の連続性を不当に侵害されないことを含む。

本プロジェクトでは、これと技術的な監査概念を分ける。

---

# 4. Transformation History Integrity

暗号技術は、

**同じ自分であること**

そのものを証明できない。

一方で、

**自分がどのように変化したか**

の履歴は検証可能にできる。

これをTransformation History Integrityと呼ぶ。

対象:

- model update
- memory modification
- policy changes
- permission changes
- stimulation events
- firmware changes
- emergency overrides

---

# 5. 精神的オフライン権

精神的オフライン権は単なるright to disconnectではない。

## Offline Survivability

外部接続なしでも最低限の認知機能を維持する。

## Portability

認知データやPersonal AIを移行できる。

## Exit

サービス事業者との関係を終了できる。

## Local Control

鍵、ポリシー、重要な認知データの最終統制を本人が持つ。

この意味で、精神的オフライン権は**認知機能についてvendor lock-inされない権利**でもある。

---

# 6. Consent

暗号技術は、署名やcredentialの存在を検証できる。

しかし、

- 本当に理解したか
- 強制されていないか
- 判断能力が十分か
- 現在も同意しているか

を暗号だけで保証することはできない。

したがって、

**Cryptographic validity ≠ Ethical legitimacy**

である。

---

# 7. Organoid Systems

脳オルガノイドの計算利用は研究されているが、現在のオルガノイドに人間レベルの記憶、人格、自己意識があると示されたわけではない。

そのため、

> オルガノイドが長期記憶や人格形成に統合される

という部分は将来仮説として扱う。

仮に将来そのような統合が起きた場合には、セキュリティだけではなくmoral statusの問題が生じる。

---

# 8. Core Principle

Human–AI融合そのものを禁止することが目標ではない。

重要なのは、

**変化する自由**と  
**変化させられない自由**

を同時に守ることである。
